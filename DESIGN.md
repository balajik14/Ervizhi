# Ervizhi (ஏர்விழி) Design System

## Global Configuration
* **Theme Name**: Nature Green
* **Mode**: Light Mode Default (Dark Mode support)
* **Design Philosophy**: Modern, organic, and accessible for Tamil Nadu farmers.

## Color Palette
* **Primary Color**: #2E7D32 (Nature Green) - Used for primary actions, headers, and active states.
* **Secondary Color**: #81C784 (Light Green) - Used for secondary actions, tags, and highlights.
* **Background Color (Light)**: #F1F8E9 (Light Green Tint) - Used for app background.
* **Background Color (Dark)**: #1B5E20 (Dark Green) - Used for dark mode backgrounds.
* **Text Color (Primary)**: #212121 (Dark Grey)
* **Text Color (Secondary)**: #757575 (Medium Grey)
* **Error Color**: #D32F2F (Red)
* **Warning Color**: #FBC02D (Yellow)
* **Success Color**: #388E3C (Green)
* **Organic Toggle Color**: #FF9800 (Orange) - Used when the Organic Toggle is ON to shift UI accents.

## Typography
* **Font Family**: 'Mukta Malar', 'Inter', sans-serif (Supporting Tamil Script)
* **Headings**: Bold, readable, clear hierarchy.
* **Body Text**: Regular, easy to read for users with varying levels of literacy.

## Layout & Components
* **Card Style**: Slightly rounded corners (8px), subtle shadows for depth.
* **Buttons**: Pill-shaped or rounded rectangles, clear call-to-action text.
* **Inputs**: Large touch targets (minimum 48px height), clear borders, descriptive labels.
* **Navigation**: Bottom navigation bar for easy one-handed use on mobile devices.

## Accessibility
* High contrast ratio for text and backgrounds.
* Clear iconography alongside text labels.
* Support for larger text sizes.
